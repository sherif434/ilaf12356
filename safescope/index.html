الفحوصات المضمنة

  • رؤوس الأمان المفقودة
  • علامة انعكاس نصية غير تنفيذية
  • مؤشرات تسريب أخطاء قواعد البيانات
  • فحص HEAD لمسارات ثابتة محدودة
  • رصد التحويل الخارجي دون اتباعه
  • مراجعة أساسية للاستجابة والخادم

الحدود الأمنية

  • لا توجد حمولات SQL هجومية أو XSS تنفيذية
  • لا تخمين كلمات مرور أو تجاوز مصادقة
  • لا توجد طلبات POST أو PUT أو DELETE
  • لا زحف عشوائي ولا اتباع للتحويلات
  • النتائج مؤشرات وليست إثباتًا قاطعًا للثغرات

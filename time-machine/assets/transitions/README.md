# TIME MACHINE transition videos

Place the seven supplied MP4 files in this folder using these exact names:

- egypt.mp4 — Ancient Egypt
- greece.mp4 — Ancient Greece
- rome.mp4 — Augustan Rome
- persia.mp4 — Achaemenid Persia
- indus.mp4 — Indus Valley
- china.mp4 — Han dynasty China
- maya.mp4 — Ancient Tikal / Maya

The site references these relative paths: `assets/transitions/<name>.mp4`.

A Mesopotamia/Babylon transition video was not present in the uploaded ZIP. Add `mesopotamia.mp4` when available and add this entry to `transitionVideos` in `index.html`:
`meso:'assets/transitions/mesopotamia.mp4'`

Until the MP4 files are uploaded to this folder, the site displays the built-in title fallback for that transition.

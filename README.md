# Washing Shop Car Care — Client Booking System

واجهة عربية RTL بنفس الهوية البصرية الأصلية، مع نظام حجز وحسابات عملاء ولوحة إدارة متصلة بـ Supabase.

## المزايا
- تسجيل دخول وإنشاء حساب برقم الهاتف وكلمة مرور.
- خانة كلمة المرور تظهر بعد إدخال رقم الهاتف، وتبدأ افتراضيًا بقيمة مخفية قابلة للتعديل.
- حساب شخصي للحجوزات والمفضلة وتغيير كلمة المرور.
- حجز خدمة مع السيارة واليوم والساعة والملاحظات.
- حالات الحجز: قيد الانتظار، تمت الموافقة، جاري التجهيز، تم التسليم، ملغي، تم الرفض.
- لوحة إدارة محمية حسب صلاحية الحساب.
- إحصائيات الحجوزات والعملاء والإيرادات.
- خدمات وعروض ومركبات وعناوين ومراجعات وإشعارات في قاعدة البيانات.
- Row Level Security على جداول البيانات.
- Dark / Light Mode.
- تجربة موبايل مخصصة ومتجاوبة.
- بدون WhatsApp داخل الموقع حسب المطلوب.

## قاعدة البيانات
المشروع يستخدم Supabase Auth + PostgreSQL + RLS.

### إعداد حساب الإدارة
بعد إنشاء أول حساب للمالك/الموظف، يتم رفع صلاحية الحساب إلى `manager` أو `admin` من قاعدة Supabase باستخدام معرّف المستخدم، ثم تظهر لوحة الإدارة لهذا الحساب فقط.
